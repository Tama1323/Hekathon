## 📌 Ringkasan Eksekutif Proyek

**NetraNav AI** adalah aplikasi pemandu mobilitas dan perlindungan keselamatan pejalan kaki penyandang tunanetra (*visually impaired*) berbasis kecerdasan buatan (*Edge Computer Vision*) dan umpan balik sensorik ganda (*Spatial Audio & Haptic Feedback*). 

Berbeda dengan aplikasi global seperti Google Lookout atau Microsoft Seeing AI yang berlatensi lambat (3–5 detik) dan boros internet, **NetraNav AI** dirancang khusus untuk kondisi nyata infrastruktur di Indonesia dengan **pemrosesan langsung di perangkat (*on-device*) berkecepatan <100 milidetik**, mendeteksi lubang selokan (*manholes*), undakan rusak, rintangan setinggi kepala, serta dilengkapi tombol darurat otomatis (*Fall Detection SOS*).

## 🎯 4 Pilar Keunggulan Kompetitif (Unfair Advantage)

1. **Zero Hardware Cost:** Tidak memerlukan tongkat pintar mahal seharga Rp 8–10 juta. Cukup smartphone Android yang sudah dimiliki pengguna.
2. **Ultra-Low Latency (<100ms):** Model Edge AI berjalan offline di ponsel, tidak bergantung pada koneksi internet cloud yang sering lambat di jalanan.
3. **Dual Sensory Output (Haptic + Audio Singkat):** Mencegah *audio overload*. Pengguna tetap dapat mendengarkan suara lalu lintas di sekelilingnya demi keselamatan maksimal.
4. **Local Context Trained:** Mampu mendeteksi rintangan khas Indonesia (lubang got tanpa penutup, motor di trotoar, dan terpal/spanduk rendah PKL).
